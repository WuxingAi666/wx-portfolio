# 架构、取舍与面试讲解

## 请求路径

浏览器悬浮组件 -> FastAPI 入站校验 -> SQLite 请求预约 -> 历史指代改写
-> Query Embedding -> FAISS -> 相似度筛选 -> Prompt -> DeepSeek 流式生成
-> SSE -> 安全 DOM 渲染与资料引用。

LangChain 的 TextLoader、RecursiveCharacterTextSplitter、Embeddings、
FAISS、ChatPromptTemplate、ChatOpenAI 共同组成链路。
没有手写分词、关键词重合度或“固定答案伪装模型”。

## 工程取舍

### 公开知识与个人隐私

data/public 是单独维护的公开知识源，不读取旧 knowledge.txt 或公司文件。
项目描述经源码与本人经历核对，没有证据的效果指标不写入；资料同时标明原型与待验证部分。
不收录原来的薪酬信息，技术方案以本交付代码为准。
回答与检索片段会经过第三方模型服务；这不是全离线推理方案。

### 向量距离

文档与问题都使用 FAISS normalize_L2=True 归一化。
底层平方 L2 距离 d 换算为 cosine=1-d/2。阈值默认 0.40，
它是语义接近的筛选参数，不是答案可信度百分比。应根据真实问题集调整。
索引指纹包含数据、清单、切分参数、模型提供方、端点和分块上下文版本；更换模型或上下文方案必须重建。每个分块补充本人及所属文档标题，避免技术段落离开标题后丢失主题；仍以完整语义向量做召回，不使用关键词加分。

### 索引文件

TextLoader 加载每份 TXT，清单赋予资料标题和网站锚点，覆盖本机路径元数据。
内容存 JSON，向量存 FAISS 二进制，元数据保存 SHA-256 完整性校验。
避免 pickle 反序列化；校验用于检测意外损坏，不代替文件系统权限。
运行时只使用自己生成、持久化卷中的可信索引。

### 多轮与依据

访客历史由浏览器携带，后端限制条数及总字数。模型先将追问补全为独立检索问题，
然后召回公开片段，生成时只允许以这些片段为事实来源。
历史是理解指代的数据，不能把访客声称的经历写入知识库。
[S1] 引用表示召回资料标记；当前未做逐句事实核验，不能保证每个引用都绝对正确。
无召回时直接提示资料不足，不额外调用生成模型。

### 配额与并发

SQLite BEGIN IMMEDIATE 原子预约。全局每日 300 次、单 IP 每日 60 次、
每分钟 6 次，代码默认最多 4 个在途请求、当前云服务器配置为 2，均可配置。失败请求也计入请求额度，
避免攻击者反复触发付费上游。重启不清空当天额度。按 UTC 日历日重置。
不信任访客自行传入的 X-Forwarded-For；代理部署仅在内部可信网络启用代理头。
限流能控制单次服务成本，不能代替 DDoS 防护；IP 共享和分布式访问都有局限。
如需多机部署，需把限流和索引管理改为共享基础设施。

### 日志与错误

记录请求 ID、路径、状态和耗时，不记录问题、答案、原始 IP 和上游响应体。
SQLite IP 哈希使用服务端随机盐；管理员统计接口单独鉴权。
访客错误不返回异常堆栈、绝对路径或上游密钥。
SSE 已建立后错误通过 error 事件返回，不把流内错误误认为完整答案。
客户端停止或断开时取消上游任务并释放并发预约。

### 前端

阅读布局使用浅灰画布与独立白色模块面板，项目置于关于之后、实习之前。六个项目采用单列、每项一层外框：明显标题、摘要与两条核心实现直接排版，技术词经过安全转义后使用黑色粗体；技术标签、源码或说明、RAG 助手和记账本体验入口保留。项目图片集中到详情，不在列表展示。
详情顺序为项目介绍、设计背景与目标、核心功能与个人实现、技术栈与处理链路、难点与设计取舍、项目图片、当前状态与边界、相关入口。背景依据现有事实整理，图片保持比例并明确标注示意；完整内容保留在静态 HTML 的原生 details 中。
projects.js 将同一份详情内容移动到居中原生 dialog：桌面最大 860×780，手机保留少量边距自适应；入场采用短暂浅角度翻折与标题栏渐变扫光，正文无模糊，背景为单色遮罩。支持焦点恢复、Tab 循环、Escape、遮罩关闭及浏览器前进后退。独立 #details-* 链接可直接打开项目；禁用 JavaScript 时仍可展开 details 阅读全部内容。
完整简历不在主导航或全页独立模块中，首屏、实习和联系区提供按钮。resume.js 将静态 details 中的唯一一份简历移动到原生 dialog（桌面最大 1080×900，手机保留边距），关闭后归还。支持 #resume 直达、前进后退、键盘焦点和无 JavaScript 阅读回退。打印按钮和 beforeprint 将完整简历复制至 body 级独立打印根节点，避免弹窗高度与滚动裁剪；afterprint 清理副本。项目与简历通过 portfolio:open-modal 事件协调，保证只打开一个内容弹窗。
移动端向下阅读后，助手入口收为带完整无障碍名称的小图标，减少遮挡；入口拖动与助手窗口行为保持一致。动画尊重 prefers-reduced-motion。

个人网站延续白底蓝色风格，内容围绕业务分析、编码实现、全栈交付与沟通排障组织。
实习展示区采用项目背景和与完整简历一致的八条贡献，区分雇主、驻场客户与协同团队，覆盖驻场沟通、流程表单、六级审批、迁移排障、测试验收及协同交付。业务交付单张卡片按四阶段组织：需求接收分析与客户复盘确认、按确认方案实施与反复测试、生产上线与交付演示、持续维护与问题关闭。强调客户确认和业务使用结果，限定为实施实习生对业务模块的参与。贡献数字沿用既有简历，不将协同排障描述成独立完成全部代码修复。奖学金为连续三年校级三等奖学金，公开 TXT 同步。
各内容区使用黑色标题、深灰正文和中灰辅助文字，以黑色粗体强调贡献。关键词气泡为淡蓝底深字；技能用四级蓝色与对应图例表达实践程度，最深色为白字，并保留文字分组。页面使用纯白面板和统一浅灰画布；导航保持纯白背景及稳定高度。独立助手采用森林绿标题、浅苔绿画布、暖白回答气泡和更明确的边框与双层阴影，与网站蓝色和白底区分。
resume.css 为主要按钮、导航、联系入口和助手操作提供统一悬停反馈；主要按钮仅轻微上浮和渐变扫光。翻折与扫光尊重 prefers-reduced-motion，精细鼠标设备才启用悬停位移，助手入口只改阴影以兼容拖动。
模块首次进入视口时通过 IntersectionObserver 触发 Web Animations API 轻移：桌面 10px / 420ms，手机 6px / 300ms，同批最大延迟 80ms。正文始终可见，不添加模糊或透明度；每项只播放一次，不依赖动画保证内容可见。点击与键盘聚焦会取消所在卡片入场动画，减少动画设置改变时取消在途动画并断开观察。鼠标悬停气泡上浮 2px 和浅阴影，手机触控不启用；纯展示标签不改为可点击光标。
入口显示「问问仵星的RAG问答助手」，窗口标题为「仵星的RAG问答助手」，恢复森林绿与暖白配色，使用本地 SVG 嫩芽笑脸头像；入口、标题、欢迎页与回答身份统一。头像相对脚本路径解析，兼容子目录部署，图片禁用原生拖拽。悬停轻微摆动遵循减少动画设置。
组件样式使用 pa- 前缀隔离。默认小窗 400×560，短屏默认高度不超过视口的 80%，给拖动保留空间；标题栏拖动，八个边缘 / 角手柄调整尺寸。
最小手动尺寸 340×400（小于此视口时以屏幕为界），放大模式最多 960×800，并受视口约束。默认尺寸与用户自定义尺寸分别处理；键盘缩放依据当前实际大小计算，避免短屏首次缩放突然变大。
普通小窗和放大窗口分别记录位置；还原恢复自定义大小和位置；最小化保留对话与进行中的生成。
Pointer Capture 处理鼠标与触摸手势，拖动点击分开，窗口在移动、拉伸、视口变化后均约束在屏幕内。
双击标题栏切换大小；标题支持方向键移动和 Home 复位，右下角手柄支持键盘调整尺寸。
手机对话全屏，保留入口拖动；visualViewport 同步可视区域高度以改善软键盘遮挡输入区的情况。
模型文本通过 textContent / 文本节点渲染，有限支持加粗和来源链接，
不会把模型 HTML 注入页面。只允许本站及公开作品集来源链接。
sessionStorage 按标签页隔离保存最多 40 条消息及输入草稿和字号偏好；发往后端的检索历史最多 8 条、合计 6000 字，单条截取至 2000 字；服务器不存聊天正文。
清空对话不抹掉配额，关闭面板保留本次会话，取消回答不进入下次历史。
分类提问和随机问题只辅助选题，不用于检索打分。复制、Markdown 导出、字号切换、窗口重置及连接检查收纳于消息操作或更多菜单；来源以安全文本和受限链接显示。流式生成时允许输入下一条草稿。每轮先锚定回答开头，内容增长后停止追尾；只有“回到最新”显式开启流式跟随，滚轮 / 触摸 / 指针 / 阅读键操作暂停跟随。完成、停止或异常时捕获 scrollTop，在格式化正文、来源、操作、追问及输入状态更新后恢复，不再强制滚到底部；聊天区关闭浏览器自动滚动锚定，避免与应用逻辑竞争。失败或停止的整轮不进入后续检索上下文。

外层 pa-window 容器查询按实际宽高调整标题、欢迎页、留白和输入区；内层 pa-chat 容器控制灵感面板的滚动方式。短窗口采用紧凑欢迎布局，正文保持 14px、较大字号仍为 16px。ResizeObserver 观察窗口并重算 textarea 高度与最新内容提示，观察回调不滚动聊天；手机沿用 visualViewport 高度 / 偏移，键盘挤压后输入上限 72px，保留 16px 编辑字号和触控按钮尺寸。
顶部工具栏仅保留单一简历入口与更多菜单；新对话位于更多菜单并二次确认。「提问灵感」位于输入框上方独立工具行；米白内容、深绿标题及独立阴影的二级浮层在对话区内展开，浅绿遮罩仅覆盖聊天区。展开时底层聊天使用 inert 避免焦点和点击穿透，关闭后恢复操作；点击遮罩、Escape 恢复到灵感按钮，点击编辑框仍可直接输入。标准高度固定标题 / 分类 / 随机选题，列表独立滚动；聊天容器高度不足 280px 时通过容器查询切换整体滚动，适配缩小窗口、横屏和键盘挤压。开合保留聊天位置、草稿和完整输入框尺寸，不插入聊天记录。Web Animations API 提供 220ms 浮起和 130ms 淡出，反向操作从当前帧衔接并取消旧动画，减少动画时即时完成；不模糊或持续晃动正文。生成中禁用直接提问选项，允许随机选题起草下一问并在本轮完成后保留。欢迎页仅展示两个开场问题，延伸追问默认折叠。回答正文使用 14px 深字，深绿用户气泡和暖白回答气泡区分角色；输入区以较深的浅绿底、白色编辑区、「你的问题」标签及深绿发送按钮区分。

### 内容同步与本地验收

sync-project-content.py 从项目 JSON 生成项目展示、简历项目和六份项目 TXT；sync-knowledge.py 从最终静态网站和完整简历同步其他公开主题。两者支持只读 --check，CI 与 scripts/check-local.py 均检查同步状态。知识文件、模型、切分参数构成索引指纹，资料变化后重建并重启 API。
2026-10-29 起效果验证统一使用本地网站与本地 API，sync-local.py 只同步本地待发布副本及候选压缩包；最终成品明确要求发布后才部署。已发布版本与本地工作状态分别记录在 PROJECT-STATUS.md 和 output/local-sync.json。

## 当前规模与后续扩展

交付面向低流量个人作品集，采用单进程和只读知识源。
未实现多租户、访客上传、账号系统、分布式任务、商业级高可用或支付。
不为规模预先增加 Redis、关系数据库集群或外部向量数据库。
后续可依据实际评测添加重排序、语义缓存、可选验证码或 WAF，
并通过独立数据集衡量改进，避免只增加技术名词。
