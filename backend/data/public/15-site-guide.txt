【问答助手的使用】
悬浮入口名为问问仵星的RAG问答助手，窗口标题为仵星的RAG问答助手。电脑支持拖动、缩放、放大还原、最小化；手机适配可视区域。基于公开资料语义检索生成回答，可连续追问、停止、重试、查看来源。新增提问灵感、随机问题、复制回答、导出对话、字号切换、草稿恢复和回到最新回答。对话只保存在当前标签页，导出文件由访客主动下载。

【部署事实】
网站与 FastAPI 问答后端统一部署到自有 Ubuntu 云服务器，入口为 http://8.152.192.126/wx/ 。Nginx 提供 HTTP 静态网站并反向代理同域问答接口，systemd 管理后端常驻与故障重启，FAISS 索引和 SQLite 配额独立持久化。GitHub 保存完整前后端源码，不通过 GitHub Pages 发布本网站。默认使用外部 BGE-M3 Embedding 和 DeepSeek API，不是全离线推理。
