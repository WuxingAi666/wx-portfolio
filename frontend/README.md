# 个人作品集网站 · 独立前端

原生 HTML / CSS / JavaScript，无 npm 构建要求。
包含六个项目、实习、业务交付、技能、校园与联系，支持项目详情与完整可打印简历。
森林绿 RAG 小窗支持拖动缩放、流式回答、来源、停止重试、连续追问、灵感、复制与导出。

在本目录启动静态服务：

```powershell
python -B -m http.server 8932 --bind 127.0.0.1
```

打开 http://127.0.0.1:8932/。单独运行前端可以浏览全部作品和简历；生成问答需要同时启动独立 RAG 后端。
本地自动连接 127.0.0.1:8010。同域云端自动使用网站所在的 /wx/ 目录作为 API 基址。
跨域部署时在 js/assistant-config.js 的 apiBase 设置真实 API 基址，并在后端允许该前端 Origin。

index.html 维护个人与实习等文案，content/projects.json 维护项目事实。
在完整主工程运行内容同步脚本生成项目 HTML 与知识；不要独立修改生成的 TXT。
图片、css、js 都在本目录；模型密钥只在后端，前端源码和公开包不包含真实密钥。
