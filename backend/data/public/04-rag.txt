【个人作品集网站 × RAG 智能问答助手】
面向面试官快速了解个人经历的需求，将作品集网站、公开知识库、独立问答服务与私有对话看板组合为完整应用。网站与 API 同域运行；访客连续追问并核对来源，管理员按匿名访客和会话回看问答、处理反馈。
材料依据：完整源码、接口边界测试与前后台联调。当前状态：已上线 · 语义问答与私有看板。

【实际实现与实践】
检索与生成：TextLoader 加载 TXT，LangChain 重叠分块，BGE-M3 向量化与 FAISS 语义召回，再由 DeepSeek 基于资料生成回答。
前后端交互：原生 JavaScript 聊天小窗支持拖动缩放、SSE 流式回答、停止重试、来源展开、回答复制与对话导出，配套分类提问、草稿恢复和手机全屏适配。
服务与交付：FastAPI 提供问答接口，配套索引持久化、调用额度、并发限制与边界测试；Nginx 同域托管前端并反向代理，systemd 管理常驻服务。
记录与管理：SQLite 独立保存匿名访客、会话、逐轮问答及引用，记录完整、停止和中断状态；私有看板支持访客备注、收藏与已读、日期筛选、统计趋势、JSON / CSV / Markdown 导出和自动刷新。

【设计与边界】
追问如何保留主题：结合最近对话补全检索问题，再进行向量召回；历史帮助理解指代，公开资料作为事实依据。
知识更新如何生效：通过脚本同步项目事实、网站与简历资料；知识内容、向量模型和切分配置共同生成索引指纹，以 FAISS 二进制与 JSON 保存索引，更新后重建并重启服务。
公开体验如何控制成本：SQLite 原子预约控制单 IP / 全局额度及并发；浏览器不持有模型密钥，模型文本通过安全 DOM 节点展示。
流式记录如何兼顾体验：首段回答保存检查点，后续约每秒更新，结束前提交最终记录；后台每 5 秒发现变化，保留阅读位置和引用展开。记录异常不阻断访客问答，后台显示异常状态。
后台与业务数据如何隔离：问答记录、调用额度与 FAISS 分开存储，删除聊天不重置额度，私聊不自动进入知识库。管理员以独立密码登录，使用 HttpOnly 会话与同源写操作校验；记录默认保留 30 天。
个人网站、RAG API 与私有对话看板统一部署。匿名编号区分浏览器，不能确认真实姓名；看板仅管理员登录查看。默认使用外部 BGE-M3 与 DeepSeek API，不是全离线推理；公开体验按额度控制，Token 统计不等于完整账单。

【配置细节】
TextLoader 加载公开 TXT，RecursiveCharacterTextSplitter 默认按 420 字符分块、80 字符重叠；默认硅基流动 BAAI/bge-m3 向量，可切换本地 BGE。生成模型接入 DeepSeek Chat API，具体模型名以配置为准。
