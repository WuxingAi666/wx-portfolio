【问答助手的使用】
悬浮入口名为问问仵星的RAG问答助手，窗口标题为仵星的RAG问答助手。电脑支持拖动、缩放、放大还原、最小化；手机适配可视区域。基于公开资料语义检索生成回答，可连续追问、停止、重试、查看来源。支持提问灵感、随机问题、复制回答、导出对话、字号切换、草稿恢复和回到最新回答。浏览器保存当前标签页聊天和草稿；服务端独立保存匿名问答，默认保留 30 天，不自动加入知识库。

【私有对话看板】
管理员登录后按匿名访客、会话、逐轮问答查看内容，支持称呼备注、收藏、已读和新追问重新未读、搜索及北京时间日期筛选、统计趋势、JSON / CSV / Markdown 导出。流式回答保存检查点，后台每 5 秒同步并保留阅读位置。匿名编号只能区分浏览器，不能确认真实姓名；后台不公开展示访客对话，不向访客提供管理凭据。

【部署事实】
网站与 FastAPI 问答后端统一部署到自有 Ubuntu 云服务器，原入口为 http://8.152.192.126/wx/ 。Nginx 提供静态网站并反向代理同域接口，看板使用 HTTPS 与管理员会话认证。systemd 管理常驻与故障重启，FAISS、SQLite 配额和问答记录独立持久化。GitHub 保存完整前后端源码，不通过 GitHub Pages 发布本网站。默认使用外部 BGE-M3 Embedding 和 DeepSeek API，不是全离线推理。
