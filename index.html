果蔬成熟度智能检测系统

核心项目 · P1

基于 YOLOv8 + ResNet50 的果蔬检测与成熟度分类桌面系统。自建 8000+ 张标注数据集，支持图片、视频、摄像头、批量目录四种推理模式，检测结果实时呈现于可视化表格，并可导出标注后的检测视频。

  • 双模型架构：YOLOv8 目标检测定位果实区域 + ResNet50 成熟度分类，综合识别准确率 93%。
  • 工程化桌面端：PyQt5 + OpenCV 构建 GUI，QThread 后台线程执行推理避免界面卡顿，GPU / CPU 环境自适应。
  • 结果可视化与交互：检测框绘制、目标下拉筛选、置信度 / IOU 阈值实时调节、检测视频后台导出与进度反馈。
难点与解决方案
光照干扰 →果园实拍图存在过曝、阴影视差，单一归一化泛化差。前置自适应预处理流水线：白平衡校正 + CLAHE 限制对比度直方图均衡 + 通道归一化，统一不同光照下果实表观特征，降低误检。
小目标漏检 →果实密集场景下小果（远处 / 遮挡）易漏检。基于 k-means 对标注框聚类重设计锚框（anchor）适配果实尺度分布，提升输入分辨率并增加小目标检测层；配合 NMS 阈值调优抑制重叠误框，小目标召回率明显改善。
成效 →预处理 + 锚框优化将综合识别准确率提升至 93%，误检率下降，密集果实场景鲁棒性增强。

BOSS 直聘自动化投递助手

核心项目 · P2

浏览器脚本 + FastAPI 后端 + 实时看板三层架构的求职辅助工具：基于大模型 API 生成个性化招呼语与对话回复，投递记录持久化存储，并通过 SSE 实时推送至监控看板。

  • 页面交互层：Tampermonkey 用户脚本实现滚动加载、焦点、键入、点击事件模拟，多选择器方案适配不同页面结构。
  • 智能对话引擎：接入 DeepSeek API，结合职位上下文生成招呼语与多轮回复，支持失败重试。
  • 数据与看板：SQLAlchemy + SQLite 持久化投递日志与每日统计，SSE 实时推送，看板呈现今日、累计数据与投递明细。
  • 四层风控：限速等待、频控识别、异常熔断、拟人化操作，控制运行频率（设计逻辑见下方难点）。
难点与解决方案
页面改版适配 →BOSS 页面随版本迭代，DOM 结构变动致脚本定位失效。为关键元素（职位卡、沟通按钮、输入框）维护多组候选选择器，运行时按「先主后备、命中即停」逐级匹配，单点失效不影响整体；页面解析抽为独立模块，改版只更新选择器配置。
反爬与风控应对 →平台对高频自动化有频控与校验。设计四层策略：① 分级等待 + 随机化操作间隔模拟真人节奏；② 频控弹窗 / 滑块校验识别并暂停重试；③ 连续异常（被拦截 / 无响应）触发熔断降级，规避账号风险；④ 拟人化操作序列（滚动、停顿、非匀速键入）。限速参数集中配置、默认保守。
成效 →多次页面改版下仍可稳定运行，结合限速与熔断将自动化对平台影响控制在低水平，仅用于个人求职辅助。

中文语音情感识别系统

P3 · 毕业设计

声学 + 语义双通道的语音情感识别系统：HuBERT 声学分类、Whisper 语音识别与 DeepSeek 语义分析并行，动态加权融合输出情感结论。

  • HuBERT 微调情感分类，CASIA 中文情感语音数据集（1200 条 · 6 类），准确率 79.6%。
  • ASR + LLM 语义 + 声学特征动态加权 Late Fusion。
  • FastAPI 分层后端 + Vue3 + Element Plus + ECharts 前端。
难点与解决方案
低信噪比声学优化 →真实录音含环境噪声与混响，信噪比低致声学模型掉点。前端加 VAD 剔除静音段、谱减法 / 维纳滤波降噪；特征层用 HuBERT 深层语义表征替代浅层 MFCC，对噪声更鲁棒；对低质量样本做加噪、变速、混响数据增强提升泛化。
多模态融合权重调优 →声学与语义在不同样本置信度不一致，固定权重易偏科。采用动态加权 Late Fusion——以各模态在验证集上的置信度 / 一致性为权重自适应融合，并对长尾情感类别做类别加权损失缓解不均衡；经网格搜索确定最优融合系数。
成效 →CASIA 六类中文情感数据集上准确率达 79.6%，低信噪比样本与长尾类别识别稳定性提升。
